# EVAQUEST website

Static GitHub Pages site for EVAQUEST PVT. LTD.

## Hosting
Enable GitHub Pages in repository Settings → Pages, source: Deploy from a branch, branch: main, folder: / (root).

Custom domain: evaquest.co (CNAME file included). Configure Wix DNS A records for @ to 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 and CNAME www to evaquestinfo-svg.github.io. Preserve email MX/TXT records. Enable Enforce HTTPS once the certificate is ready.

## Forms
Forms use mailto and require the visitor's email client. No registration database or resume storage exists. Add secure backend and privacy policy before collecting sensitive candidate data.
